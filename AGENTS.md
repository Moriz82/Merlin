# Project rules

This source repository is public. Work on main. Do not publish client records, credentials, or runtime data.
Use Astra for planning and design. Use Terra or Sol where each fits. Main owns contracts and migrations. Do not change another worker's files.
Use source and synthetic fixtures only. No scanners, exploit runners, AI transports, or harness imports.
Record exact dependencies and licenses before reuse. Use short, direct English.
Run backend tests, frontend tests, build, and git diff --check before a release.
